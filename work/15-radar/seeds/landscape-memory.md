# Landscape Memory

The what-is-cooking tracker. One row per THEME, never per item. This is what lets the radar say
"this is the fourth independent thing pointing the same way" instead of reporting four stories.

**The count is the whole point, and it is a DEDUPED count of independent events** (Run Check 1). The
same launch covered by five outlets is ONE event with corroboration 5, not five events. Getting that
backwards is how a system convinces itself a trend exists because one story was loud.

| Theme | First seen | Last seen | Independent events | Notable players | Trajectory | Amplified? | Note |
|-------|-----------|-----------|--------------------|-----------------|------------|------------|------|
| _(the radar appends rows here)_ | | | | | | | |

- **Trajectory:** accelerating · steady · cooling
- **Amplified?:** `yes` when the coverage grew but the independent-event count did not. That is the
  flag for a story being repeated rather than a thing actually happening, and it is the most useful
  column here.

## Pruning
A theme with no new independent event in 90 days goes to cooling. A theme cooling for another 90
days gets archived with its dates kept. Nothing is deleted: a theme that died is a real finding, and
it is the finding you will want the next time the same idea comes back wearing a new name.
