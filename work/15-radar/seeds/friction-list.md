# Friction List

The radar's demand side. A table of things that currently annoy you, and what you do about them
today. Every sweep checks new arrivals against THIS list before generic scoring: a tool that kills a
listed friction outranks a more impressive tool that kills nothing, whatever it scores on hype.

**This ships empty on purpose.** Your frictions are yours. A borrowed list sends the radar hunting
for a fix to a problem you have never had, and it will find one, and you will read about it every
week.

## How to fill it
Add a row the first time you build a workaround for something. That is the reliable signal: a
workaround is a friction you have already paid for once. You do not need to brainstorm this list,
just notice when you are doing something manually for the second time.

`Weight` is High / Medium / Low, and it is how badly it costs you, not how hard it is to fix.

## How the sweep uses this
1. After fetch and dedup, check every surviving item against the table above BEFORE generic scoring.
2. A friction match is stated out loud in the presentation ("this kills friction #2") and justifies
   a maxed Leverage score.
3. A friction-killer is presented even in a week when nothing else clears the bar.
4. This page doubles as the standing answer to "is there a better tool now for something I already
   do by hand": every workaround row IS that watchlist.

## Keeping it honest
When something kills a friction, **strike the row through and date it rather than deleting it**. The
record of what used to hurt is how you notice, a year later, that you stopped noticing. A list that
only ever grows is a list nobody prunes; a list that silently shrinks is a list nobody can audit.
